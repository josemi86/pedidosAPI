Rest API\
Lenguaje: Java 17\
Versión Springboot: 4.1.1\
Versión Maven: 3.9.16

Arquitectura: Arquitectura de capas\
Patrones de diseño: Inyección de Dependencias, Data Transfer Object, Manejo Global de Excepciones.

Endpoints:\
POST /api/v1/users\
GET /api/v1/users/{user_id}\
GET /api/v1/orders/search?query={query}\

La aplicación se puede iniciar desde la IDE o desde la terminal con el commando mvn spring-boot:run

Documentation: OpenAPI Specification (OAS)\
Index endpoint: /swagger-ui/index.html#/\
